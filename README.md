# 刷题笔记
算法刷题笔记仓库，用于记录我在各平台的刷题过程、解题思路和总结。

## 注意问题
每学完一类题目，编写该类题目的解题模式和技巧总结.  
不要只贴代码，记录思考过程、尝试过的方法和犯过的错误，便于复习  
添加图解，对于复杂算法，可以添加手绘图或流程图
